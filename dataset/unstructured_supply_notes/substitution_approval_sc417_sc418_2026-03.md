# Substitution Approval - SC-418 as Alternate for SC-417

Engineering has approved SC-418 (Grain Flow Sensor Module - Enhanced v2) as
a validated substitute for SC-417 on Harvester platform units, subject to
limited compatibility conditions:

- Approved for Harvester X9 1000-series and 1200-series units running
  controller firmware v4.2 or later.
- NOT YET validated for the 1200-series high-output build specification
  currently run at Plant P2 - a firmware interoperability test on that
  specific build spec is still pending as of this note.
- No approval has been issued for any other platform (Tractor, Combine,
  etc.) at this time.

Any plant wishing to use SC-418 as a near-term substitute for SC-417 must
confirm build-spec compatibility with Product Validation before
substitution on the shop floor. See substitution_rules.csv
(substitution_id referencing original_part_id = SC-417, substitute_part_id
= SC-418) for the formal record.
